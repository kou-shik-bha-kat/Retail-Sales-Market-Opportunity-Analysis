# 📊 Retail Sales & Market Opportunity Analysis

## 📌 Project Overview

An Excel-based retail sales analysis project designed to identify sales patterns, store performance, product opportunities, profitability, and market trends using approximately 359K transactional sales records.

The project combines product, store, and sales data and transforms raw business data into meaningful KPIs, analysis, and an interactive dashboard.

---

## 🎯 Business Objective

The objective of this project is to analyze retail sales performance and identify potential market opportunities by answering key business questions:

- Which store locations generate the highest sales and profit?
- Which locations have the highest sales and profit per store?
- How do sales change over time?
- Which product categories contribute the most to revenue?
- How does product pricing relate to sales performance?
- What is the average basket value and basket size?
- Which locations demonstrate stronger customer purchasing behavior?

## 📂 Dataset

The project contains three main datasets:

### Products
Product-level information including product name, category, cost, and price.

### Stores
Store-level information including store, city, location, and opening date.

### Sales
Transactional sales data containing approximately **359K records**, including sales date, store, product, units sold, cost, price, sales, and profit.

---

## 📈 Key KPIs

| KPI | Description |
|---|---|
| Sales / Revenue | Total value of products sold |
| Profit | Revenue after product cost |
| Units Sold | Total products sold |
| Transactions | Number of sales transactions |
| Basket Value | Average value per transaction |
| Basket Size | Average units per transaction |
| Profit Margin | Profit as a percentage of sales |
| Sales per Store | Average sales generated per store |
| Profit per Store | Average profit generated per store |
